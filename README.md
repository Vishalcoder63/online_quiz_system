# 🎓 Online Quiz Management System  

An online quiz management system built with **PHP, MySQL, HTML, CSS, and Bootstrap**. This project allows admins to create and manage quizzes, while students can register, attempt quizzes, and view their results instantly.  

---

## 🚀 Features  

- 🔐 **Secure Authentication**: Separate login for Admin and Students  
- 📝 **Admin Panel**:  
  - Create, manage, and delete quizzes  
  - Add multiple-choice questions (MCQs)  
  - View student performance with graphs  
- 🎯 **Student Panel**:  
  - Attempt quizzes assigned by admin  
  - Get instant score and feedback  
  - Review past results  
- 📊 **Result Analytics**: Visual representation of scores using charts  
- 📱 **Responsive Design**: Works on desktop and mobile  

---

## 🛠️ Tech Stack  

- **Frontend**: HTML, CSS, Bootstrap  
- **Backend**: PHP  
- **Database**: MySQL  
- **Server**: Apache (XAMPP / WAMP)  

---

## ⚙️ Installation  

1. Clone this repository  
   ```bash
   git clone https://github.com/your-username/quiz-management-system.git
   ```
2. Import the database  
   - Open `phpMyAdmin`  
   - Create a new DB (e.g., `quiz_db`)  
   - Import the `.sql` file from the project  
3. Update `config/db.php` with your DB credentials  
4. Run project in browser  
   ```
   http://localhost/quiz-management-system/
   ```
